RGA Price App — v2.3.1 (icon cache fix)
=======================================

APPLYING
--------
Extract ON TOP of your existing stonewater-price-app folder and let it
overwrite. Do NOT delete the folder first — this zip does not contain your
.git/ history or your data/*.xlsx source spreadsheets, because those were
never uploaded.

  unzip -o rga-price-app-v2.3.1.zip -d /path/to/PARENT-of-stonewater-price-app

Note "PARENT". If you extract inside the repo folder you get a nested
stonewater-price-app/stonewater-price-app/ and nothing takes effect.

After extracting, run `git status`. Expect modifications to:
  netlify.toml, package.json, CHANGELOG.md
  site/index.html, site/manifest.webmanifest, site/sw.js

If git reports data/ as deleted, stop and restore before committing.

  git add -A
  git commit -m "v2.3.1 — icon cache fix"
  git push


WHY THIS PATCH EXISTS
---------------------
netlify.toml served /icons/* with `max-age=31536000, immutable`. That header
tells a browser never to revalidate. v2.3.0 replaced the icons but reused
their filenames, so any device that had opened the app already kept the old
amber icons for a year no matter what was deployed.

Two changes fix it:
  1. Icon URLs now carry ?v=2.3.0 — a changed URL is the only way out of an
     immutable cache entry a client already holds.
  2. /icons/* is now max-age=86400, must-revalidate. `immutable` is only
     correct for content-hashed filenames; yours are stable, so the old header
     would have hidden every future icon change too.

Bump the ?v= value whenever the icon artwork changes.


YOUR IPHONE
-----------
The deploy alone will NOT repaint the home-screen icon. iOS copies the icon
into the springboard when a shortcut is added and never refetches it — that
cache is separate from HTTP and nothing server-side can reach it.

  1. Deploy this patch and wait for Netlify to finish.
  2. On the iPhone, press and hold the app icon -> Remove App -> Delete.
  3. Open the site in Safari. Pull down to refresh once.
  4. Share -> Add to Home Screen.

The new navy icon appears. Anyone else with it pinned needs the same steps.

You can delete this file once applied.
